# 우테코 8기 프리코스 1주차 미션 - 문자열 덧셈 계산기

## 기능 구현 목록

### 입력 기능
- **덧셈할 문자열 입력(기본 구분자)**
  - [x] 쉼표(,) 또는 클론(:)을 구분자로 가지는 문자열을 입력


- **덧셈할 문자열 입력(커스텀 구분자)**
  - [x] 기본 구분자(쉼표, 콜론)을 제외한 커스텀 구분자를 지정하여 입력
  - [x] 커스텀 구분자의 경우에는 문자열 앞부분에 "//"와 "\n" 사이에 위치하도록 하여 입력

---

### 출력 기능
- **입력 안내 메시지 출력** 
  - [x] 덧셈할 문자열을 입력받을 수 있도록 안내 메시지 출력


- **결과 출력**
  - [ ] 기본 구분자와 커스텀 구분자로 구분된 숫자들을 모두 더하여 그 결과를 출력
  - [ ] 빈 문자열이 입력된 경우, 0을 출력

---

### 핵심 기능
- **구분자 추출**
    - [x] 기본 구분자(쉼표, 콜론)는 어플리케이션 실행 시 기본적으로 항상 사용할 수 있는 구분자이어야 함 
    - [x] 덧셈할 문자열이 입력되고, 문자열 앞부분에 "//"와 "\n" 사이에 위치하는 문자가 있는 확인
      - [x] "//"와 "\n" 사이에 문자가 존재하면, 해당 문자를 커스텀 구분자로 지정하여 기본 구분자와 커스텀 구분자로 숫자를 구분
      - [ ] "//"와 "\n" 사이에 문자가 존재하지 않는다면, 기본 구분자로만 숫자를 구분


- **구분자로 지정된 문자를 기준으로 숫자를 구분 및 추출**
    - [x] 문자열 앞부분 "//"와 "\n" 사이에 위치하는 커스텀 구분자가 있는 경우, "\n"문자를 기준으로 뒤에 있는 문자열을 기본 구분자 및 커스텀 구분자로 구분하여 숫자들을 추출
      - [x] 커스텀 문자가 ";"라고 가정하고, "\n" 문자 뒤에 "nn1;a2$;3$$"와 같은 식으로 되어있는 경우에도 1+2+3=6의 결과가 나와야 함
    - [ ] 문자열 앞부분 "//"와 "\n" 사이에 위치하는 커스텀 구분자가 없는 경우, 전체 문자열을 기본 구분자로 구분하여 숫자들을 추출


- **추출된 모든 숫자들의 총합 계산**
    - [ ] 추출된 모든 숫자들을 모두 더하기

---

### 예외 처리
  - [ ] '구분자'와 '양수'로 구성되지 않은 문자열인 경우 예외 처리
  - [ ] "//"와 "\n" 사이에 구분자가 '문자'가 아닌 '문자열'이 입력된 경우 예외 처리
  - [ ] "//"와 "\n" 사이에 '문자'가 아닌 '숫자' 등이 들어오는 경우 예외 처리
